Kraken for the Baofeng DM-32UV

Install Kraken

About 5 minutes. Your radio is backed up first, and nothing leaves this computer.

  • The USB programming cable
  • A charged battery
  • Chrome or Edge on a computer
  • Firmware DM32.00.01.048 (checked for you)

Chrome then asks which device to use. Pick your cable, usually USB-Serial Controller.

  1. Connect
  2. Back up
  3. Install
  4. Done
